## 1. Система уровней откровенности

В OnlySex предусмотрено пять уровней откровенности:

1. **Сексуальный разогрев**
2. **Откровенные ласки**
3. **Полноценный секс**
4. **Жёсткие эксперименты**
5. **Максимальная откровенность**

Перед началом игры участники самостоятельно выбирают стартовый уровень. Текущий уровень можно изменить между ходами, при этом изменение применяется только к следующему заданию.

Приложение самостоятельно не повышает и не понижает уровень. Конкретные задания внутри выбранного уровня выпадают случайно.

## 2. Уровень 1 — Сексуальный разогрев

Назначение: начать игру сразу с сексуальных действий, без долгих романтических вступлений.

В задания входят:

* частичное или полное раздевание;
* откровенные поцелуи и прикосновения;
* ласки груди, ягодиц и внутренней стороны бёдер;
* прикосновения к гениталиям через одежду;
* демонстрация тела партнёру;

* эротический массаж;
* возбуждение партнёра руками без доведения до оргазма.

На первом уровне ещё нет оральных ласк, проникновения и использования проникающих игрушек.

На втором уровне ещё нет полноценного вагинального или анального полового акта.

## 4. Уровень 3 — Полноценный секс

Назначение: перейти к полноценным сексуальным действиям и смене различных сценариев.

На третьем уровне ещё нет анального секса, жёсткого доминирования и экстремальных практик.

## 7. Формирование задания

После встряхивания телефона приложение случайно выбирает задание, соответствующее текущей игровой ситуации.

При выборе задания учитываются:

* текущий уровень откровенности;
* количество участников;
* пол каждого задействованного участника;
* совместимость участников с ролями, предусмотренными сценарием;
* наличие необходимых секс-игрушек;
* задания, уже показанные в текущей сессии.

Для каждого участника выбирается один из трёх вариантов пола:

* мужчина;
* женщина;
* небинарный участник.

Если в сценарии участвует небинарный участник, приложение использует для его роли универсальные действия, не зависящие от конкретных половых органов.

К универсальным относятся:

* анальные практики;
* использование подходящих секс-игрушек;
* связывание и ограничение движений;
* доминирование и подчинение;
* эротический массаж;
* поцелуи, прикосновения и другие действия, не требующие конкретной физиологии.

В тексте задания участники обозначаются выбранными тотемами. Приложение всегда указывает роль каждого задействованного тотема: кто выполняет действие, кто его получает, кто участвует во взаимном действии и кто наблюдает.

Для двух участников сценарий может предусматривать действие активного игрока для партнёра, действие партнёра для активного игрока или взаимное действие обоих участников.

Для трёх участников приложение может выбрать сценарий:

* с участием активного игрока и одного случайно выбранного партнёра;
* с одновременным взаимодействием всех троих;
* с действием двух участников для третьего;
* с взаимодействием двух участников при участии или наблюдении третьего.

Активный игрок всегда входит в число участников сценария, но не обязательно является единственным исполнителем действия.

Одно и то же задание не повторяется в пределах текущей сессии, пока не будут использованы все подходящие задания выбранного уровня.

Текст задания формируется с использованием выбранных тотемов и однозначно указывает роль каждого задействованного участника: кто выполняет действие, кто его получает, кто участвует во взаимном действии и кто наблюдает.

## 9. Penalty для двух и трёх участников

Перед началом игры каждый участник самостоятельно выбирает одно Penalty из случайно предложенных вариантов.
Для режима с двумя участниками получателем Penalty всегда становится второй игрок.

Для режима с тремя участниками:

* если Penalty рассчитано на одного получателя, приложение случайно выбирает одного из двух партнёров;
* если Penalty рассчитано на двух получателей, в нём участвуют оба партнёра;
* активный игрок заранее знает содержание выбранного Penalty, но не знает, кому именно оно будет предназначено;
* получатель или получатели определяются только после нажатия **PASS**.

После выполнения Penalty ход считается завершённым, и телефон передаётся следующему участнику.

## 10. Последовательность хода

Каждый ход проходит в следующем порядке:

1. Приложение показывает тотем участника, чья очередь наступила.
2. Телефон передаётся этому участнику.
3. Участник встряхивает телефон и становится активным игроком.
4. Приложение выбирает подходящий сценарий, определяет задействованных участников и распределяет между их тотемами роли.
5. На экране отображается задание с указанием тотемов всех задействованных участников.
6. После появления задания активному игроку доступны три действия:

    * **ВЫПОЛНЕНО** — задание выполнено, ход завершается;
    * **PASS** — задание отменяется и открывается заранее выбранное Penalty;
    * **STOP** — игра немедленно заканчивается без выполнения задания или Penalty.

7. После выполнения задания или Penalty приложение показывает тотем следующего участника.
8. Телефон передаётся дальше, и начинается новый ход.

## 11. Изменение уровня во время игры

Текущий уровень откровенности отображается на экране между ходами.
Перед следующим встряхиванием участники могут выбрать любой уровень от 1 до 5. Новый уровень применяется к следующему и всем последующим заданиям, пока участники снова его не изменят.
Уровень нельзя изменить после того, как задание уже выпало. Для отказа от текущего задания используются только **PASS** или **STOP**.
Изменение уровня не сбрасывает очерёдность игроков, выбранные Penalty и список уже показанных заданий.

## 12. Повторение заданий

Для каждого уровня приложение отдельно хранит список заданий, уже показанных в текущей сессии.
Пока остаются неиспользованные подходящие задания, ранее показанные задания повторно не выпадают.
Когда все подходящие задания выбранного уровня использованы:

* список использованных заданий этого уровня очищается;
* задания снова становятся доступными для случайного выбора;
* последнее показанное задание не может выпасть два раза подряд.

Переход на другой уровень не очищает списки уже показанных заданий. Все списки полностью удаляются после завершения сессии.

## 13. Задания с таймером

Некоторые задания могут содержать заданную продолжительность.

Для таких заданий:

1. Сначала активный игрок полностью читает задание.
2. Таймер не запускается автоматически.
3. Игрок нажимает кнопку **«НАЧАТЬ»**, когда участники готовы.
4. Во время выполнения на экране отображается оставшееся время.
5. По окончании телефон подаёт звуковой и вибрационный сигнал.
6. После этого игрок нажимает **«ВЫПОЛНЕНО»**, и ход завершается.

Задания без установленной продолжительности выполняются без таймера. Участники самостоятельно определяют момент их завершения.

## 14. Подготовка игры

Перед началом новой сессии приложение последовательно предлагает:

1. Выбрать количество участников: два или три.
2. Выбрать пол каждого участника: мужчина, женщина или небинарный участник.
3. Выбрать для каждого участника уникальный тотем.
4. Отметить имеющиеся секс-игрушки.
5. Выбрать стартовый уровень откровенности.
6. По очереди выбрать личное Penalty для каждого участника.
7. Проверить итоговые настройки и начать игру.

При выборе личного Penalty телефон передаётся соответствующему участнику. После подтверждения выбор скрывается, и приложение предлагает передать телефон следующему игроку.

После завершения настройки приложение случайно выбирает первого активного участника и показывает его тотем. Далее очередь идёт по кругу в порядке добавления участников.
